## 一、简介
## 1.1 功能简介
结果筛选功能支持通过自定义的筛选条件对报表数据进行过滤，仅展示符合条件的数据内容。该功能可用于聚焦特定范围的数据，提升数据分析的针对性与效率。

## 1.2 使用场景
适用于需要按条件筛选、聚焦展示某部分数据的场景，例如：

+ 仅查看某类商品的销售数据
+ 筛选出销量高于平均水平的商品
+ 展示指定负责人或区域的数据

## 2.2 功能设置步骤
### 2.2.1 汇总前筛选
**汇总前筛选**是指在数据聚合前，对最底层原始数据进行筛选，被筛选字段的范围是报表数据源的所有字段。通过设置多个筛选条件（支持“且”“或”逻辑），可灵活过滤目标数据，以确保后续汇总结果更贴近分析需求。

<img src="https://cdn.nlark.com/yuque/0/2025/png/43099917/1754017314833-5f82e002-8993-4636-a376-2db144125169.png" width="2880" title="" crop="0,0,1,1" id="ucf909a56" class="ne-image">

1. **添加条件：**

点击条件按钮，进入条件设置界面

2. **选择筛选字段**

筛选字段即被筛选的字段

+ 可作为筛选字段的有：单行文字、多行文字、数字、链接、日期、起止时间、电话、邮箱、下拉选择、多项选择、图片选择、地址、单项选择、定位、数据关联、引用、成员、部门、编号、申请人、申请时间、更新时间、当前流程状态和表格内以上字段类型。
3. **选择判断符**

判断符是用来设置筛选逻辑的，确定数据是否满足逻辑。**不同筛选字段可以选择判断符的范围不同。**

> ****[**附录1 筛选字段和判断符的匹配关系**](#aStRZ)
>

4. **输入筛选内容**

筛选内容：数据是否满足筛选条件的参考依据。**不同类型的筛选字段可输入的筛选内容不同。**例如，当日期字段的显示格式为「年月」且判断符选择「动态范围」时，可以选择「本月」「上月」「下月」「今年」「去年」「明年」。

<img src="https://cdn.nlark.com/yuque/0/2026/png/69131865/1788494737080-cd6d41df-b130-4ab8-b07f-50c9a6dcb000.png" width="2916" title="" crop="0,0,1,1" id="u9c565cf3" class="ne-image">

> [附录2 筛选字段和筛选内容的匹配关系](#a8aLX)
>

5. **设置且条件**

点击且条件按钮，可以添加多个筛选条件，只有同时满足所有条件的数据才会通过筛选

6. **设置或条件**

点击或条件按钮，可以添加多个筛选条件，数据满足其中一个条件就可以通过筛选

### 2.2.2 汇总后筛选
**汇总后筛选**即在报表完成数据聚合后，根据聚合结果筛选出符合条件的数据记录，被筛选字段的范围仅为指标类字段。通过设置“且”**与**“或”逻辑，可灵活组合多个筛选条件，实现多维度分析与精准筛选。

<img src="https://cdn.nlark.com/yuque/0/2025/png/43099917/1754019784093-8cebb61f-9f6e-445e-8de0-350ce03c519b.png" width="2880" title="" crop="0,0,1,1" id="uc373de8f" class="ne-image">

1. **添加条件**

点击条件按钮，进入条件设置界面

2. **选择筛选字段**

筛选字段即被筛选的字段

+ 可作为筛选字段的有：单行文字、多行文字、数字、链接、日期、起止时间、电话、邮箱、下拉选择、多项选择、图片选择、地址、单项选择、定位、数据关联、引用、成员、部门、编号、申请人、申请时间、更新时间、当前流程状态和表格内以上字段类型。
+ 汇总后筛选的筛选字段只能从指标类字段中选择
3. **选择汇总方式**

可以选择求和、平均数、中位数三种不同的汇总方式，设置筛选字段的计算方式

4. **选择判断符**

判断符即设置判断逻辑，确定数据是否满足逻辑。汇总后筛选可选的判断符号如下：

+ 等于/不等于
+ 大于/大于等于
+ 小于/小于等于
+ 等于任意一个/不等于任意一个
+ 为空值/不为空值
5. **输入筛选内容**

筛选内容即数据是否满足筛选条件的参考依据

:::info
⚠️汇总后筛选只针对数字字段进行筛选，因此输入筛选内容时只能输入数值

:::

6. **设置且条件**

点击且条件按钮，可以添加多个筛选条件，只有同时满足所有条件的数据才会通过筛选

7. **设置或条件**

点击或条件按钮，可以添加多个筛选条件，数据满足其中一个条件就可以通过筛选

# 三、注意事项
1. 漏斗图和明细表只支持汇总前筛选，其他轻析报表既支持汇总前筛选又支持汇总后筛选

| 图表类型 | 汇总前筛选 | 汇总后筛选 |
| :---: | :---: | :---: |
| 汇总表 | 支持 | 支持 |
| 明细表 | 支持 | 不支持 |
| 条形图 | 支持 | 支持 |
| 雷达图 | 支持 | 支持 |
| 折线图 | 支持 | 支持 |
| 饼状图 | 支持 | 支持 |
| 柱状图 | 支持 | 支持 |
| 漏斗图 | 支持 | 不支持 |
| 地图 | 支持 | 支持 |


2. 在使用表格子字段进行筛选时，需要注意以下规则：
+ **行内匹配逻辑**：当表格有多行数据时，且筛选条件为且条件时，系统会要求筛选条件必须在**同一行**内同时满足，才会筛选出该行数据。
+ **不支持跨行匹配**：如果部分条件满足在第 1 行，另一部分条件满足在第 2 行，则不会被筛选出来。

示例说明：  
表格字段「订单明细」包含以下数据：

| 商品名称 | 数量 | 状态 |
| --- | --- | --- |
| A产品 | 5 | 已发货 |
| B产品 | 10 | 未发货 |


筛选条件：

+ 订单明细·商品名称 = A产品
+ 订单明细·状态 = 已发货

✅ 结果：第一行同时满足两个条件，这条数据可以被筛选出来。

筛选条件：

+ 订单明细·商品名称 = A产品
+ 订单明细·状态 = 未发货

❌ 结果：第一行满足第一个条件，第二行满足第二个条件，但它们不在同一行，因此不会被筛选出来。

| 为空值 | 所有字段 | 字段内容为空时，满足条件 |
| 不为空值 | 所有字段 | 字段内容不为空时，满足条件 |
| 动态范围 | 日期字段 | 选择一个时间段，当筛选字段的日期在该时间段内时，满足条件支持可选内容：今日、昨日、明日、本周、上周、下周、本月、上月、下月、今年、去年、明年、近7天、近30天、近90天、上季度、本季度、下季度 |
| 从属 | + 成员字段<br/>+ 部门字段 | 可以按照部门和角色筛选人员，当筛选字段中的人员属于所选择的部门或者角色时，满足条件 |
| 不从属 | + 成员字段<br/>+ 部门字段 | 可以按照部门和角色筛选人员，当筛选字段中的人员不属于所选择的部门或者角色时，满足条件 |
