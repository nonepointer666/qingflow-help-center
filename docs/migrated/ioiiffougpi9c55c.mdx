## 一、功能简介
工作区的流币套餐和成员配额分别在 QMC 与轻流主站中管理：

| 管理内容 | 操作入口 | 作用 |
| --- | --- | --- |
| 流币套餐 | QMC | 开通、升级、降级或取消工作区的流币套餐 |
| 成员配额 | 轻流主站 | 成员查看个人配额，或由工作区管理员设置成员可使用的流币额度 |


QMC 不提供成员配额设置入口，轻流主站也不负责开通或调整流币套餐。

## 二、在 QMC 中管理流币套餐
### 2.1 开通流币套餐
符合开放条件的正式企业智能版工作区，可以在 QMC 现有的订阅或拓展服务流程中开通流币套餐。QMC 不会新增独立的「流币套餐」一级菜单。

1. 进入 QMC 现有的订阅或拓展服务流程。
2. 为符合条件的工作区选择流币套餐档位。
3. 按页面提示完成开通。

可选套餐如下：

| 套餐 | 每周期额度 |
| --- | ---: |
| 1x | 12,000 流币 |
| 5x | 60,000 流币 |
| 20x | 240,000 流币 |


套餐周期最长为 30 天，从开通时开始计算。如果工作区权益提前结束，流币套餐也会随工作区权益到期。

### 2.2 升级、降级或取消套餐
在 QMC 中调整套餐时，不同操作的生效时间如下：

| 操作 | 生效规则 |
| --- | --- |
| 升级套餐 | 立即生效，并从升级时重新开始一个新周期 |
| 降级套餐 | 当前周期结束后生效 |
| 取消 5x 或 20x 套餐 | 当前周期结束后回落为 1x |
| 取消 1x 套餐 | 1x 为基础套餐，不能取消为无套餐 |
| 修改尚未生效的降级或取消 | 可以继续修改，也可以撤销 |


已关闭的套餐仍可在 QMC 现有的「已关闭服务」中查看。

> 升级会立即开始新的套餐周期，不会等到原周期结束。
>

### 2.3 流币使用顺序
工作区同时拥有套餐周期额度和永久余额时，会优先使用套餐的周期额度。

+ 套餐周期结束后，未使用的周期额度不会结转到下一个周期。
+ 永久余额不会因套餐周期结束而受到影响。

### 2.4 操作状态不明确时如何处理
如果开通、调整或取消套餐时出现超时或状态不明确，请先核对套餐状态、服务项状态和流币余额。

> 状态未确认前不要重复提交，以免产生重复操作。
>

## 三、查看个人成员配额
所有已有效登录的成员都可以查看自己的流币配额。

操作路径：进入「个人中心」→「流币用量」→「成员 AI 用量与额度」。

在「成员 AI 用量与额度」页面中，可以查看：

+ 当前工作区是否开启成员配额限制；
+ 当前账号是否已经配置配额；
+ 当月已用量和累计已用量；
+ 月度配额或总配额的剩余额度；
+ 月度用量历史。

无论工作区是否开启配额限制、当前成员是否配置额度，或额度是否已经用尽，「成员 AI 用量与额度」卡片都会保留，并显示对应的状态说明。

## 四、配置成员额度
只有工作区管理员可以配置成员额度，普通成员无法查看或访问该入口。

操作路径：进入「更多」→「管理后台」→「流币统计」→「配额管理」。

### 4.1 开启或关闭成员配额限制
1. 进入「配额管理」。
2. 根据工作区需要，开启或关闭成员配额限制。
3. 查看成员的当前用量和剩余额度。

启用配额限制后，没有有效配额的成员不能发起新的 AI 消费请求。

### 4.2 设置成员配额
管理员可以为成员设置以下内容：

| 配置项 | 说明 |
| --- | --- |
| 月度配额 | 限制成员在每个自然月内可使用的流币额度 |
| 总配额 | 限制成员累计可使用的流币额度 |
| 启用状态 | 设置该成员的配额是否启用 |


管理员还可以查看成员用量、剩余额度和配额历史变更。

## 五、成员配额计算规则
| 规则 | 说明 |
| --- | --- |
| 月度配额 | 按自然月统计 |
| 总配额 | 累计统计成员历史可归属用量 |
| 修改额度 | 管理员修改额度不会清空成员的历史用量 |
| 未配置有效配额 | 工作区开启限制后，该成员不能发起新的 AI 消费请求 |
| 配额用尽 | 月度配额或总配额任一项用尽，后续新请求会被限制 |
| 并发请求 | 配额在请求发起前进行软限制；并发请求可能造成实际用量短暂超过额度，超出后发起的新请求会被阻止 |


## 六、注意事项
> 流币套餐决定工作区可使用的周期额度，成员配额决定成员在工作区内可使用的额度，两者需要分别在 QMC 和轻流主站中管理。
>

+ 套餐升级立即生效并重新计算周期；降级或取消在当前周期结束后生效。
+ 5x、20x 套餐取消后会回落为 1x，1x 不能取消为无套餐。
+ 套餐周期额度未使用完时不会结转，永久余额不受套餐周期影响。
+ 工作区开启成员配额限制后，未配置有效配额或额度已经用尽的成员不能发起新的 AI 消费请求。
+ 管理员修改成员额度不会清空历史用量。
