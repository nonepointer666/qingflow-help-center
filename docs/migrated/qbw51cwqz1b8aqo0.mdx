## 1. 简介
### 1.1 功能简介
通过可自定义的逻辑对数据进行筛选，依据筛选结果在当前字段中显示目标数据

### 1.2 使用场景
适用于需要对数据进行区分过滤的场景。例如当前字段关联会员信息字段时，可以使用筛选条件功能筛选显示某个会员的相关信息

## 2. 设置步骤
### 2.1 功能入口
选择一个需要设置筛选条件的字段，点击「设置筛选条件」按钮，即可设置筛选条件

### 2.2 功能配置步骤
#### 2.2.1 简易模式
**简易模式**：根据简单且固定的筛选格式确定筛选条件

**选择关联应用字段**

关联应用字段：被筛选的字段，可以在关联应用的部分字段中选择。点击「关联应用字段」旁的下拉三角即可选择关联应用字段

+ 可作为关联应用字段的有：单行文字、多行文字、数字、链接、日期、起止时间、电话、邮箱、下拉选择、多项选择、图片选择、地址、单项选择、定位、数据关联、引用、成员、部门、编号、申请人、申请时间、更新时间、当前流程状态和表格内以上字段类型。

## 3. 注意事项
+ 当筛选条件中的两个数字字段小数位数不统一时，系统会自动使用0补齐位数
+ 使用「粘贴筛选条件」功能后，原有的所有筛选条件设置都会被替换为粘贴的筛选条件
+ 不能在一个筛选条件中同时设置「简易模式」和「高级模式」的筛选条件
+ 除「引用」字段外的其他字段，都需要设置「关联已有数据」后，才能使用「筛选条件」功能
+ 筛选条件中包含已删除应用时，无法进行粘贴
+ 当两个筛选条件的字段来自不同应用时，无法互相复制粘贴筛选条件
+ 选择判断符中的「等于任意一个」与「不等于任意一个」不支持Q-robot、数据关联与关联报表中的匹配模式
+ 日期字段筛选匹配如果日期格式不一致，以左边日期格式进行数据筛选匹配，格式不一致可能导致数据筛选不到，筛选匹配条件建议使用相同格式的日期字段。
+ 单值字段等于多值字段筛选匹配，多值字段有且只能有一个值才能匹配成功，比如申请人等于成员，成员字段应该只含有一位成员，否则筛选匹配失败，无法筛选出符合条件的数据。
+ 字段关联、Q-Linker和代码块的返回数据时，统一按照单行文本的格式进行筛选匹配。
+ 在使用表格子字段进行筛选时，需要注意以下规则：
    - **行内匹配逻辑**：当表格有多行数据时，且筛选条件为且条件时，系统会要求筛选条件必须在**同一行**内同时满足，才会筛选出该行数据。
    - **不支持跨行匹配**：如果部分条件满足在第 1 行，另一部分条件满足在第 2 行，则不会被筛选出来。

示例说明：  
表格字段「订单明细」包含以下数据：

| 商品名称 | 数量 | 状态 |
| --- | --- | --- |
| A产品 | 5 | 已发货 |
| B产品 | 10 | 未发货 |


筛选条件：

+ 订单明细·商品名称 = A产品
+ 订单明细·状态 = 已发货

✅ 结果：第一行同时满足两个条件，这条数据可以被筛选出来。

筛选条件：

+ 订单明细·商品名称 = A产品
+ 订单明细·状态 = 未发货

❌ 结果：第一行满足第一个条件，第二行满足第二个条件，但它们不在同一行，因此不会被筛选出来。
